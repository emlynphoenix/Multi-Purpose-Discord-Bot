# Sparkles Discord Bot
A multi-purpose Discord bot with ticketing, moderation, and utility commands, built with Pycord.

## Features
- Ticket system for support requests
- Moderation commands (kick, ban, mute, warn)
- Custom welcome messages

## Built with
- Python 3.12
- Pycord
- SQLite

## Setup
1. Clone the repo: `git clone https://github.com/emlynphoenix/repo-name`
2. Install dependencies: `pip install -r requirements.txt`
3. Add your bot token to a `.env` file: `DISCORD_TOKEN=your_token_here`
4. Run: `python main.py`
